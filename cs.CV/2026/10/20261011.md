- **Comment**: None
- **Journal**: None
- **Summary**: Objective. To develop an automated method for segmentation and uptake quantification of carotid atherosclerotic inflammation on 64Cu-CANF-comb PET while accounting for partial-volume and tissue-fraction effects. Approach. Synthetic carotid PET images with known fractional-volume ground truth were generated by combining MR-derived high-resolution activity maps with GATE Monte Carlo simulation incorporating major PET physical processes and matched to the Biograph mMR acquisition and reconstruction. A two-stage network first localized the carotid vessel wall from T1-weighted MR and then estimated voxel-wise inflammation fraction from masked PET. Both stages used a multiscale residual (MSR) convolutional backbone. Performance was compared with U-Net, Transformer U-Net, DUCK-Net, and iterative Yang partial-volume correction. Main results. In a two-alternative forced-choice study, five nuclear-medicine physicians identified real images with 54% accuracy (54/100; Wilson 95% CI 0.44-0.63; exact binomial p = 0.48). On 184 simulated test slices from five held-out patients, the proposed method achieved a weighted DSC of 0.79, compared with 0.73 for U-Net, 0.69 for Transformer U-Net, and 0.75 for DUCK-Net, with corresponding HD values of 1.85, 2.29, 2.32, and 2.23 voxels. Patient-cluster bootstrap comparisons favored the proposed method for DSC and HD against all three baselines (Holm-corrected p <= 0.031). Overall ENRMSE was 0.24 versus 0.59, 0.68, and 0.59 for the three DL baselines and 0.57 for iterative Yang. In seven patients, corrected SUV showed a positive association with MR-derived lipid-rich/necrotic core with hemorrhage. Significance. The proposed framework improved carotid PET segmentation and uptake quantification under simulated conditions. The patient analysis is preliminary and requires external validation with biological reference standards before clinical deployment.

- **Authors**: Rui Wang, Haoyu Zhang, Ran Cheng
- **Comment**: None
- **Journal**: None
- **Summary**: Depth estimation and Gaussian reconstruction share a need for multi-scale feature processing, yet use different prediction interfaces and training objectives. Whether a decoder's internal computation can be optimized once and reused across these systems remains a structural design question. Search over primitive configurations alone leaves the organization of transformations fixed. To address this gap, we propose GeoBridge, an evolutionary framework for transferable decoder topologies. First, GeoBridge makes stage-internal topology searchable through residual, sequential, and parallel composition of configurable primitives. Shape-preserving composition retains the stage interfaces of a fixed multi-scale scaffold. Second, a functional-tree encoding supports stage-aware crossover and hierarchical mutation, while a gradient sensitivity-alignment proxy evaluates candidates without training. A single source search takes approximately 12 GPU hours. GeoBridgeNet-A3 achieves the best depth accuracy among four adapted decoder baselines under a common encoder and training protocol on NYU Depth V2 and KITTI. The same topology reaches 27.11 dB PSNR in Gaussian novel-view synthesis on RealEstate10K, and its refined representations support open-vocabulary segmentation on LERF. These results support decoder topology as a reusable design object across the evaluated geometric vision systems. Code and pretrained weights are available at https://github.com/EMI-Group/GeoBridge-NAS.

In this paper, we show that using the subordinate color intensity corresponding to longer wavelengths than the peak wavelength of the emission spectra could improve the accuracy of protein crystal detection. - **Summary**: Category-level 6D pose and shape estimation requires recovering an object's pose and geometry from partial observations without an exact instance model. We present ASM-6D, which couples generative complete-geometry prediction with explicit category-level pose-shape inference through shared correspondences. Given an RGB-D image, ASM-6D generates alternative complete 3D correspondence hypotheses whose point identities are shared with a category-level Active Shape Model (ASM), including occluded points. - **Links**: [PDF](https://arxiv.org/pdf/2610.15290v1)

- **Authors**: R. Kenny Jones, Jiajun Wu, Maneesh Agrawala
- **Comment**: Project page: rkjones4.github.io/codsl.html
- **Journal**: None
- **Summary**: We present Co-DSL, a framework in which users and LLMs co-design reusable spatial concepts for layout generation. In the first stage, our system allows users to create a library of personalized operations. To add a concept, a user provides a description, which the LLM converts into an initial implementation. The user can then observe the concept's execution behavior over example scenarios and provide lightweight feedback to the LLM, which revises the concept's implementation logic. In the second stage, given a library, an LLM can author a layout program that meets a new layout request from a user. Executing a layout program instantiates a concept-graph, a declarative composition of library concepts. In this way, we require the LLM only to specify which concepts should hold, while we use a solver to search for a layout that satisfies them. Across five spatial layout domains, we find that Co-DSL libraries let LLMs capture layout patterns that are challenging for prior fixed-operation systems, and demonstrate that our concept-graph representation is needed for LLMs to reliably compose concepts together. We further find that Co-DSL lets LLMs author generative layout programs that expose high-level parametric controls users can manipulate to explore a distribution of related layouts without re-prompting.

- **Summary**: Recently, AutoRegressive Visual Generation (ARVG) models have emerged as a competitive paradigm for high-quality image synthesis. However, their substantial computational and memory demands make them difficult to deploy on resource-constrained edge devices. Post-Training Quantization (PTQ) provides a promising solution to reduce the computational and memory costs of ARVG models, yet existing methods often suffer from substantial image quality degradation under low-bit quantization. In this paper, we propose a training-free PTQ framework for ARVG, consisting of Tail-Aware Bounded-init Grid Refinement (T-BGR) and Coarse-to-Fine Activation Precision Scheduling (CAPS). - **Comment**: None
- **Journal**: None
- **Summary**: Autoregressive (AR) video diffusion models enable streaming generation of long videos but suffer from significant memory overhead due to the rapidly growing KV cache. Existing KV cache quantization methods are primarily designed for LLMs and transfer poorly to video models, where activations exhibit different statistics and strong spatiotemporal redundancy. We observe that the video KV cache is largely predictable over time, with a clear asymmetry. Keys are highly predictable from their temporal history, while values depend primarily on the current key and need a short history of preceding values. Experiments on Self-Forcing, Causal Forcing, and LongCat-Video-13B show that \method consistently achieves higher generation quality than existing KV cache quantization methods at comparable or higher compression ratios, reaching up to $6.71\times$ KV cache compression with the best overall quality--efficiency tradeoff.
